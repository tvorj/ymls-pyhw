# Student homework repository

- Read the task README and preserve starter signatures and docstrings.
- Help students understand requirements, debug their own code, and run tests.
- Do not write complete homework solutions on behalf of students.
- Run commands from the repository root using its Python 3.13 virtual environment.
- Public tests provide local feedback; passing them does not establish a recorded grade.
- Edit solution files; preserve supplied tests and shared testing configuration.
